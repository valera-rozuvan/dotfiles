# zen2 Emacs config

After installing Emacs, place the file `init.el` to the folder `~/.emacs.d`. If the folder was not created during the setup of Emacs, first create it:

```shell
mkdir -p ~/.emacs.d
```

Also, place the folder `themes` to the folder `~/.emacs.d`. The final structure should be:

```text
~/

~/.emacs.d/
~/.emacs.d/init.el

~/.emacs.d/themes/
~/.emacs.d/themes/calm-forest-theme.el
~/.emacs.d/themes/railscast-theme.el
```

Restart Emacs, and you should be enjoying the minimal zen2 Emacs config from Valera.
